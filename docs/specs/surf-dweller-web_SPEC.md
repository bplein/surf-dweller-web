# surf-dweller-web_SPEC.md

## Project Overview
Simple single page website for Surf Dweller.
Static build with Astro + MDX.
Hosted on Cloudflare Worker.
URL: surfdweller.org

## Technical Stack
- Framework: Astro
- Content: MDX
- Hosting: Cloudflare Worker
- Design: Blue on Gray background, Comfortaa font for logo.

## Requirements
- Single page layout.
- Background image (to be provided).
- Link to Home Owners Portal.
